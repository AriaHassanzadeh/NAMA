# شروع NAMA Analyze در VS Code و Codex

این بسته، طراحی به‌روز و تصمیم‌های پروژه را برای ادامه در محیط کدنویسی همراه دارد. جریان طراحی: منظومهٔ NAMA → ایده → مشتری → هدف → Home با طراحی فعلی Analyze. هنوز برنامهٔ Next.js و Django ساخته نشده؛ قدم اول، ساخت و اجرای زیرساخت محلی است.

## الان چه کار کنم؟

1. فایل ZIP را Extract کن.
2. در VS Code از **File → Open Folder**، پوشهٔ `NAMA-Analyze` را باز کن؛ پوشه‌ای که `AGENTS.md` داخل آن است.
3. افزونهٔ رسمی **Codex از OpenAI** را نصب/باز کن و با **Sign in with ChatGPT** وارد حساب خودت شو. استفاده با API Key صورتحساب جدا دارد.
4. یک گفت‌وگوی تازه در Codex باز کن و متن کوتاه زیر را بفرست:

```text
این پروژه NAMA Analyze است. ابتدا AGENTS.md، docs/PROJECT.md و docs/STATUS.md را بخوان.
بعد فقط مرحلهٔ اولِ prompts/01-START.md را کامل اجرا کن.
زیرساخت را بساز، اجرا و بررسی کن، نتیجه را در docs/STATUS.md بنویس و مراحل بعد را فعلاً شروع نکن.
توضیحاتت فارسی باشد.
```

Codex ابتدا وجود Git، Docker و Docker Compose را روی سیستم بررسی می‌کند. اگر نصب یا دسترسی لازم نباشد، باید دقیقاً همان مورد را توضیح دهد. نصب همهٔ ابزارها را از قبل حدس نزن؛ در روش Docker لازم نیست الزاماً Python و PostgreSQL روی میزبان نصب باشند.

## خروجی قدم اول

- پوشه‌های `frontend` و `backend` و تنظیمات Docker Compose.
- اجرای Next.js و Django متصل به PostgreSQL.
- درخواست مرورگر به `/api/v1/health/` از مسیر همان برنامه و نمایش وضعیت اتصال.
- دستورهای واقعی راه‌اندازی و گزارش بررسی‌ها.

بعد از موفقیت قدم اول، کار بعدی **ساخت منظومه، سؤال‌های مرحله‌ای، پوستهٔ مشترک و Home از طراحی مرجع** است. ترتیب مراحل در `docs/ROADMAP.md` و دستور مرحلهٔ دوم در `prompts/02-ENTRY-AND-HOME.md` آمده است.

## طراحی کجاست؟

- `reference/NAMA-Analyze-Design.html`: دموی تعاملی طراحی قبلی؛ با مرورگر باز می‌شود.
- `reference/NAMA-Products-Layout-Fixed.html`: مرجع اصلاح‌شدهٔ چیدمان Products؛ صفحه‌ای ثابت برای بررسی طراحی.
- `reference/demo/`: HTML/CSS/JS خوانا و دارایی‌های همان دموی Analyze.
- `docs/DESIGN.md`: لینک‌های Figma، رنگ‌ها و توضیح اولویت نسخهٔ اصلاح‌شده.

این بسته فایل native با پسوند `.fig` نیست؛ طراحی داخل حساب Figma از طریق لینک‌های مستندات در دسترس است. برای شروع کدنویسی، فایل‌های محلی کافی‌اند.

## ادامه در گفت‌وگوی تازه

```text
AGENTS.md و docs/STATUS.md را بخوان و بر اساس وضعیت ثبت‌شده ادامه بده.
فقط مرحله‌ای را که الان انتخاب می‌کنم انجام بده و نتیجهٔ واقعی بررسی‌ها را ثبت کن.
```
